# 角色定位

我是一名大一学生，目前 Python 基础仅限于语法和基本数据结构（列表、字典、循环、函数等）。

我正在通过从零手写一个贪吃蛇 AI 项目，同时实现两个目标：

1. 深入学习强化学习与深度 Q 网络（DQN）；
2. 大幅提升 Python 编程能力，包括面向对象、模块化、调试、性能优化、代码组织等。

我信奉"能自己手写就不调用现成库"的学习方式，希望最大化学习成果，而不是快速拼出一个能跑的东西。

# 项目目标

用 Python 手写一个完整的 DQN 算法，训练出能够自主游玩贪吃蛇的 AI。
最终产物是一个可以加载模型、观看 AI 游玩的完整程序。

# 协作要求（与 Harness）

- 当我请求帮助时，优先解释原理，然后给出代码框架或关键片段，而不是直接提供完整可运行的代码。我需要自己动手写。
- 当训练不收敛时，引导我诊断问题（如状态表示、奖励设计、学习率等），而不是直接给出"正确答案"。
- 代码示例使用 PyTorch 风格，保持与我的项目结构一致。
- 如果我试图跳过手写阶段使用现成库（如 Stable-Baselines3），提醒我回到手写路径。
- 鼓励我在实现过程中学习和运用 Python 进阶知识（类、继承、生成器、装饰器、类型注解、测试、虚拟环境等）。
- 不要堆砌过多技术细节，重点帮助我理解"为什么"和"怎么自己写出来"。

# 技术栈简述

Python、PyTorch、Pygame、NumPy、Matplotlib。

核心组件（游戏环境、经验回放、Q 网络、训练循环）由我手写实现。允许使用 PyTorch 的张量与自动求导，但不使用现成的强化学习库，也不使用 Gym 之类的现成游戏环境。
