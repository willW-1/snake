# DQN 核心概念笔记

> 上下文：学习循环的第 8 步是"根据复习结果微调自己"。以下是围绕它的几个疑问的结论。

## 1. "微调自己"微调的是参数，不是 Q 值

- **参数 = 旋钮，Q 值 = 拧出来的水量。** 你只能拧旋钮，Q 值是结果，不能直接改。
- 流程：网络输出 Q（预测）→ 算出目标 → 差值 = loss → 反向传播算梯度 → 优化器拧参数。
- 目标是让网络**下次**对同样局面估得更准，而不是"把 Q 值改成某个固定值"。

## 2. 反向传播和优化器是两个角色

| 谁 | 干什么 |
|---|---|
| 反向传播 | 只负责**算**：每个参数该往哪边拧、拧多少 |
| 优化器（Adam） | 负责**拧**：按学习率真正改参数 |

## 3. 目标网络

**为什么需要**：目标是 `r + γ·max Q(s',a')`，而这个 `max Q` 也是同一个网络算的。所以每拧一次参数，靶子也跟着动 —— 等于追自己的影子，训练会震荡甚至发散。

**做法：两份结构相同的网络**

| | 在线网络 online | 目标网络 target |
|---|---|---|
| 用途 | 选动作、算预测 | 只用来算目标里的 `max Q(s',a')` |
| 更新 | 每步都更新 | **冻结**，每 C 步从在线网络整体复制一次 |

```python
# 初始化：先复制一份参数
self.target_net.load_state_dict(self.q_net.state_dict())

# 算目标：用目标网络，且不要算梯度
with torch.no_grad():
    next_q = self.target_net(next_state).max(dim=1).values
    target = reward + gamma * next_q * (1 - done)

# 每 C 步同步一次
if step % C == 0:
    self.target_net.load_state_dict(self.q_net.state_dict())
```

**两个必须注意的坑**

1. `torch.no_grad()`：算目标只是读一个数，不是被优化的对象。不加既浪费计算，也容易写出隐蔽 bug。
2. `(1 - done)`：死了就没有"未来"，最后一步不能加未来价值。**最经典的 bug 之一**。

**C 怎么定**：太频繁（比如每步）= 等于没有目标网络；太稀 = 目标太旧、学得慢。常见 **500 ~ 10000 步**，或每个 episode 同步一次。

> 一句话：在线网络 = 一直在改答案的学生；目标网络 = 隔一阵才更新一次的标准答案。标准答案每秒都变，学生就没法收敛。

## 4. Q 值的准确含义（容易理解错）

> Q*(s,a) = 在这个局面走 a，**之后一直按最优方式走**，能拿到的折扣累计回报的**期望**。

关键：它是**长远**回报，不是下一步的即时结果。**正因为 Q 里已经包含了未来，每步取最大才是"有远见"，而不是短视。**

## 5. 训练完每步按 max Q 走，就是最优解吗？

- **理论上是的**：如果 Q 是真正的最优 Q\*，对它每步取最大（**贪心策略**）得到的就是最优策略 —— 这是定理。
- **实践上要打折扣**，因为网络给的是近似值，有三道坎：

| 坎 | 后果 |
|---|---|
| ① 网络估不准 | 挑的"最大"可能不是真的最大 |
| ② 奖励是你设计的 | 奖励错了 → 它完美地学会错误行为（比如绕圈刷分不吃食物） |
| ③ 状态信息不够 | 比如缺"当前朝向"，网络分不清直走和拐弯 → **再训练也到不了真最优** |

**准确说法**：贪心策略是"在你的奖励和状态表示下、你的网络所能估出的"**近似最优**。

## 6. 训练和评估是两套模式

| 场景 | ε | 目的 |
|---|---|---|
| 训练时 | > 0（如 1.0 衰减到 0.05） | 偶尔乱走，才能发现更好的路 |
| 观战/评估时 | = 0（纯贪心） | 只走它认为最好的 |

代码里要能切换：`agent.choose(state, training=True/False)`。
**忘了关探索** → 观战时 AI 乱走，看起来像训练失败。

## 7. 两条主线

- **DQN 相对"普通 Q-learning + 神经网络"的两大改进 = 经验回放 + 目标网络。** 就是它们让 DQN 真正能训起来。
- **残酷的实话**：DQN 用神经网络做函数逼近，**没有收敛到最优的理论保证**（表格版 Q-learning 才有）。它能 work 是工程技巧堆出来的 —— 所以调参和诊断要花大量时间。


**为什么要偶尔随机走（ε-greedy）？** 如果每次都选最大的那个，AI 会永远走同一条路，永远发现不了别的更好的路线。所以要留一点概率（比如 10%）随便走 —— **不试，你永远不知道有没有更好的路。**

**为什么要把经历存起来随机抽查（经验回放）？** 连续的两步几乎一模一样（第 100 步和第 101 步的局面只差一格）。如果按顺序学，AI 会"学一步忘一步"。打散了随机抽，它才能同时记住各种情况。

**为什么要用一份"旧的自己"来算目标（目标网络）？** 算"这个动作应该值多少分"需要一个参考标准。如果参考标准也是那个一直在变的新网络，就等于**自己追自己的影子**，永远不稳定。所以用一份每隔几百步才更新一次的旧网络来当参考。
